# Governance preflight

Before an economic change is eligible for governance activation, preflight
verifies:

- schema validation
- formal smoke
- property tests
- economic stress
- simulation
- compatibility
- release artifact identity
- supply invariants
- exact package hash
- network and chain binding
- approval validity window
- economic release-candidate hash

Installing software does not automatically activate a policy. Binary
compatibility is a readiness check, not an activation.
