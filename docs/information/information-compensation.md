# Information compensation

`HumanInformationCompensationInstruction` may use `SUNREY_COIN`,
approved fiat / application settlement, or other approved assets
according to policy.

Human Information activity does not mint unrestricted SunRey. Native
issuance remains under Chunk 71 monetary authority.

Settlement can represent:

- permission activation
- clean-room computation authorization
- compensation authorization
- usage receipt

using canonical economic / settlement infrastructure. Matching a right
never delivers raw PDV content.
