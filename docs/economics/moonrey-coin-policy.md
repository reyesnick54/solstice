# MoonRey Coin policy

MoonRey Coin is the native asset of the **autonomous productive
economy**.

Issuance remains connected to the existing
`VerifiedEconomicFact` → `VerifiedProductiveContribution` →
Global Productive Capacity Graph → `MoonReyIssuanceAuthorization` →
`MoonReyIssuanceReceipt` path.

## Hard boundaries

- An oracle observation alone cannot mint MoonRey.
- A `VerifiedEconomicFact` alone cannot mint MoonRey.
- There is no general-purpose administrator mint that bypasses
  productive contribution, eligibility, anti-double-count controls,
  or issuance authorization.
- The same contribution or authorization cannot create native supply
  twice.

Production quantities remain `UNCONFIGURED`.
