# Economic bridge

`EconomicBridgePolicy` describes legitimate flows between the human and
productive economies:

- human demand purchasing automated products/services
- productive capacity contracts
- compute consumption
- machine commerce
- human information-right computation
- SunRey/MoonRey Exchange conversion

There is **no algorithmic peg** and no intrinsic exchange ratio.

Exchange conversion uses the canonical
`SUNREY_COIN` / `MOONREY_COIN` market. Price formation comes from
simulated participants and order flow.
