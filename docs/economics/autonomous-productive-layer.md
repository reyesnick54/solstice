# Autonomous productive layer (MoonRey)

The productive layer uses Chunk 44 categories and Global Productive
Capacity Graph object concepts:

energy, compute, AI inference, robotic / automated machine output,
manufacturing, food/agriculture, water, storage, logistics, bandwidth,
resource output, real-estate utilization, and automated services.

MoonRey issuance flows only through `ProductiveEconomyEngine` after
deterministic simulated `VerifiedEconomicFacts` / productive oracle
facts satisfy fail-closed quorum, freshness, and conflict rules.

`ProductiveOutputIndex` is a **simulation measure**. It is not
real-world GDP. If a GDP-style rollup is shown, it is labeled
`SYNTHETIC_GDP_STYLE_METRIC`.

Productive coverage compares MoonRey issuance growth with verified
output growth. That is an engineering stability indicator, not a legal
asset-backing claim.
