# Economic recovery

After a recoverable stress event the laboratory checks:

- the same canonical state chain
- native SunRey and MoonRey supplies reconcile
- no duplicated issuance, settlement, or rewards
- custody reconciles
- Explorer can rebuild from the monetary books

Recovery is reported as:

- preserved invariants
- degraded availability
- recovered automatically where designed
- required operator action
- left unresolved finding

This is not a marketing security score.

When blockchain finality is unavailable, economic state does not
advance as if transactions finalized. External systems report
pending/unavailable. No synthetic accounting entries are invented to
maintain apparent continuity.

Replay a failed scenario from:

- scenario ID
- seed
- policy versions
- input fixture hash
