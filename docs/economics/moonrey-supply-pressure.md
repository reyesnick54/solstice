# MoonRey supply pressure

`MoonReySupplyPressureReport` is an engineering metric surface. It does
not make an automatic market-price claim.

## Metrics

- issuance per epoch
- issuance by category
- issuance concentration
- productive-output growth
- MoonRey supply growth
- locked quantity
- circulating quantity
- Exchange liquidity reference (`UNCONFIGURED` unless supplied)
- category dominance
- cap utilization

## Concentration

Warnings fire when issuance depends excessively on one productive
category, operator, oracle controller, productive-object class, or
region (when metadata is available). Chunk 68 independence data keeps
nominally different feeds under one controller visible as concentration
risk.

Classification: `ENGINEERING_ECONOMIC_SIMULATION`.
