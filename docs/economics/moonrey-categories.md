# MoonRey productive categories

Chunk 74 does not invent a second taxonomy. Canonical categories remain
the Chunk 44 set:

`ENERGY`, `FOOD_AGRICULTURE`, `WATER`, `MINERALS_RAW_MATERIALS`,
`REAL_ESTATE_USE`, `COMPUTE`, `AI_COMPUTE`, `MANUFACTURING`,
`LOGISTICS_TRANSPORTATION`, `STORAGE`, `BANDWIDTH_COMMUNICATIONS`,
`INFRASTRUCTURE`, `GOODS`, `SERVICES`, `AUTOMATED_MACHINE_OUTPUT`.

## Capacity versus output

Installed capacity, available capacity, reserved capacity, actual
output, verified delivery, and economic service completion remain
distinct. A capacity measurement does not automatically count as
delivered productive output. Development policy sets capacity and
independent-delivery weights to zero.
