# Chunk 94 — Developer platform guide

Register an application, issue scoped credentials, subscribe to signed
webhooks, and use Testnet or sandbox fixtures. This is the native SunRey
developer platform. It is not an EVM or Ethereum contract toolkit.

See also:

- [API authentication](./api-authentication.md)
- [Webhooks](./webhooks.md)
- [Testnet and sandbox](./testnet-sandbox.md)
- [SDK quickstart](./sdk-quickstart.md)
- [API versioning](./api-versioning.md)

```
npm run sunrey-dev -- status
npm run sunrey-dev -- app create --name demo --env SANDBOX
```

Production credentials require application approval. Approval still does
not activate production financial capabilities.
