# Production backup and recovery

Recurring verification covers:

- chain snapshots
- database backups
- configuration backups
- signer-safety data
- release and evidence archives

Restore drills run in isolated environments. Records capture actual
execution when a drill is run.

Disaster recovery ownership continues through the Chunk 55 plans.
Engineering RPO/RTO values remain `ENGINEERING_TEST_TARGETS`, not
contractual commitments.
