# Production incident command

`ProductionIncidentRecord` integrates Chunk 54/55 runbooks and Chunk 79
bounded emergency authority. There is no expanded hidden emergency
power.

Supported domains: protocol, signer, infrastructure, database, oracle,
economic, Exchange, custody, provider, security.

Critical incidents preserve logs, metrics, configuration hashes, release
hashes, chain references, audit events, and operator actions under
existing retention and privacy rules.

Human information remains off-chain, consent-bound, purpose-limited, and
Clean Room restricted. Production handoff does not weaken those
protections.
