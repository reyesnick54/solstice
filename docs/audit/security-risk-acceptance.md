# Security risk acceptance

`SecurityRiskAcceptance` is for findings deliberately not remediated.

Required fields:

- reason
- impact
- compensating controls
- expiration/review date
- human security authority
- release scope

AI cannot accept risk.

Accepted findings flow into `KnownSecurityLimitations`, release
notes, mainnet readiness, and the audit remediation bundle according
to disclosure policy. They are never hidden from release notes.
