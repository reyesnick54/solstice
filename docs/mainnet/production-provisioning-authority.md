# Production provisioning authority

AI-generated planning output is not a deployment authorization.

A `PRODUCTION` infrastructure mutation requires a distinct human
authorization package: human actor kind, required operations roles,
and an evidence digest. Fixture or engineering-only providers cannot
masquerade as production providers.

Provisioning cannot independently enable live Exchange, live custody
withdrawals, fiat rails, cards, investments, or Human Information
markets. Those remain separate capability gates.

Release authority, genesis authority, and deployment authority stay
independent. Signing a Mainnet RC does not authorize provisioning
mutation or genesis.
