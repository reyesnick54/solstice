# Fonts

Self-hosted latin-subset variable faces, the same files sunrey.xyz serves
(SunRey-website `public/fonts/`). Copied from the `@fontsource-variable/*`
packages; all three are licensed under the SIL Open Font License 1.1.

- `jost-latin-variable.woff2`: Jost (Owen Earl), display, weights 200–400
- `inter-latin-variable.woff2`: Inter (Rasmus Andersson), UI and body, weights 400–500
- `jetbrains-mono-latin-variable.woff2`: JetBrains Mono, labels and data
